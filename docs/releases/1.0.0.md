The first release of Jukebox Playlists, **1.0.0**, brings the jukebox playlists from Minecraft 26.4 Snapshot 4 to **1.16.5–26.3**.

Place a single chest directly above a jukebox and add discs. The jukebox plays automatically, swaps discs in slot order and loops through the chest. It preserves item data and the playlist position. Normal, trapped and available copper chests work; double chests are excluded.

**90 builds:** 35 Fabric, 32 Forge and 23 NeoForge. Download one `jukebox-playlists-<loader>-<minecraft>-1.0.0.jar` for your exact game version and loader, or extract the matching file from `jukebox-playlists-1.0.0-all.zip`. Install it on the server and clients. Fabric also requires a matching Fabric API.

Optional **LazoDiscs 1.0.7 + Plasmo Voice 2.1.17** support lets recordings and native discs share the same queue. The next track follows the recording's actual completion; the original disc's vanilla duration cannot truncate it. Recording URLs, titles, UUIDs, volume and radius are retained.

For **Forge 1.20.2**, replace the original PV file with `compat/forge-1.20.2/plasmovoice-forge-1.20.2-2.1.17-metadata-fix.jar` from the full ZIP, on the server and clients. This separately identified copy corrects the two Forge/FML minimums; classes and libraries are unchanged. Its license, notice, upstream source and checksums are included. Python is not needed to install it.

Recorded verification covers 90 SDK servers, 52 LazoDiscs server/audio combinations, six native client combinations, Forge 1.20.2/1.21 LazoDiscs clients, and a Fabric 26.3 dedicated server with two clients, recorded PCM and a full restart. All 90 release JARs also have their classes and runtime resources compared with the gameplay-tested baseline: only the release version, license, author and contact packaging changed. The report distinguishes exact release-file runs from that comparison and retains original test hashes.

The ZIP includes installation instructions, per-JAR SHA-256 checksums, the dependency matrix, verification details and LGPL-3.0-only license texts. Each source directory is a separate Gradle project, matching the `fabric/<version>`, `forge/<version>` and `neoforge/<version>` layout of WIGO.

Use a matching Fabric/Forge/NeoForge server. Vanilla/Paper, hybrid servers and arbitrary modpacks are outside the verified combinations. Older custom discs on 1.16.5–1.19 can need a duration setting; native discs and LazoDiscs recordings do not.

Перенос плейлистов из **26.4 Snapshot 4** на **Minecraft 1.16.5–26.3**. Всего **90 сборок** Fabric, Forge и NeoForge.

Поставь одиночный сундук над проигрывателем и положи пластинки: они запускаются сами, меняются местами по порядку слотов и играют по кругу. Записи LazoDiscs можно смешивать с ванильными треками; переход идёт по завершению настоящего аудио, данные записей сохраняются.

Скачай один JAR под свою версию и загрузчик, поставь на сервер и клиенты. Для Fabric нужна Fabric API. Для **Forge 1.20.2 + LazoDiscs** готовый исправленный Plasmo Voice находится в `compat/forge-1.20.2/` полного ZIP; замени им старый PV на сервере и клиентах. Python для установки не нужен.

В комплекте есть инструкции, контрольные суммы, результаты игровых проверок, исходники и лицензия исправления PV. Лицензия мода — **LGPL-3.0-only**. Исходники разложены по версиям и загрузчикам, как в WIGO; любую сборку можно собрать через её `gradlew`.
